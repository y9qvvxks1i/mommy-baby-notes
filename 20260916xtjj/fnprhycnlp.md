# 试管婴儿果纳芬是什么？作用以及使用步骤

> 更新时间：2026-09-16 (UTC+8)

果纳芬(Gonal-f)是一种强促性腺激素，通用名称为注射用重组人促卵泡激素，主要成份为重组人促卵泡激素α，该药物具有诱导排卵的作用，是**惠州试管婴儿****促排卵过程**中比较常见的注射类药物，同时也是治疗女性排卵障碍的通用药物。

**果纳芬为促性腺类注射药物**

果纳芬呈现形式为无菌、无热源的白色冻干粉，装于带有橡胶塞（溴丁基橡胶）和flip-off铝帽的3 ml小瓶（I型玻璃）中；另附带1支预装1ml溶剂的注射器及两个针头，两个针头为无菌包装。

**果纳芬的作用**

不少做惠州试管婴儿患者对于果纳芬的作用，可能仅知道是用来刺激多卵泡发育的，其实除此之外它还有者不少其他医学用途，该药物多用于不排卵（包括多囊卵巢综合症[PCOD]）且对枸橼酸克罗米酚治疗无反应的女性以及超排卵或辅助生育技术。

**果纳芬作用及功效说明**

另外，临床上也有部分男性服用到果纳芬，起原因是因为该药物能帮助先天或后天性因素导致的男性性腺功能不良促性腺激素水平低下，以刺激精子形成，间接的提升了男性的生育能力。

**果纳芬怎么打**

在辅助生殖技术中，果纳芬的作用是毋庸置疑的，但前提是患者能正确的使用，若是使用方法错误，不仅不能起到有效的促排卵功效，甚至还会因此而导致一些副作用，所以患者在使用果纳芬前，需明确该药物的使用方法。

**果纳芬可在医生指导下注射**

与大多数促排卵药物相似，果纳芬也属于注射类药物，因此其使用方法不如口服药物那样简单，若是盲目的进行注射，很容易相信促排卵效果，因此能否掌握果纳芬的用法用量就显得十分重要。

**果纳芬的注射步骤如下：**

1洗手，尽可能保持双手及所用物品的清洁；

2准备好注射所需用具，果纳芬药液、注射器、针头以及棉签等；

3准备注射,将注射器按上溶解药物用的针头，把全部溶剂慢慢注入GONAL-f药瓶中；

4换上细针头，排除气泡；

5用酒精棉球涂擦所选的区域（例如腹部、股前方）皮肤捏紧，以45~90 角将针头急速插入皮肤下进行注射；

6注射完毕，立即将所有针头和空瓶倒入装锐利物用的容器中。

果纳芬通常每日注射一次，患者在治疗初期一般只注射5.5-11ug的小果纳芬；每注射7天或14天都会增加2.75ug(37.5IU)或5.5 ug(75IU)的量，这个时候就会随着药品用量的增加而更换果纳芬的规格。

**果纳芬的副作用**

果纳芬虽然可以治疗多种疾病，但也存在一定的副作用，因为该药物属于激素的一种，注射后会伴随一些不良反应也是正常的，且目前出现果纳芬副作用的患者并非个例，但一经发生须及时反馈给医生，并在医生指导下采取正确解决措施。

**果纳芬常见副作用为注射部位不适**

①、轻至中度卵巢过度刺激综合症，主要表现在腹痛、腹胀、严重的卵巢增大、体重增加、呼吸困难、少尿以及恶心、呕吐和腹泻等症状；

②、多胎妊娠，使用果纳芬的患者的多胎妊娠概率高于自然妊娠，而且大多数为双胎，因为有的女性子宫环境不适合怀双胎，所以会使母体和围产期不良反应增加；

③、妊娠失败，使用果纳芬进行促排卵或辅助生育技术的患者的妊娠流产率高于自然怀孕的人群；

④、血栓栓塞，有个人或家族病史的妇女注射果纳芬后可能会增加血栓的危险性。

果纳芬虽然可以治疗多种疾病，但也存在一定的副作用，所以患者在使用果纳芬进行治疗的时候，应该首先了解治疗过程中潜在的危险性，权衡利弊之后再进行治疗，并且治疗过程中需在医生的指导下进行注射，从而减少使用之后的副作用。
